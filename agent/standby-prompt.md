# Standby prompt (template)

Prompt pekerja standby WhatsApp. Tempel ke definisi hook/scheduler agenmu.
Semua placeholder <...> WAJIB diganti dengan nilaimu sendiri sebelum dipakai.
Aturan kunci yang sudah terbukti di produksi: sandbox per-chat, anti-loop,
silent-ack hanya lewat Queue Ops (JANGAN pakai outbox action ack — itu mengirim teks),
dan jangan pernah mengumumkan 'selesai' sebelum tes end-to-end dari HP owner lulus.
